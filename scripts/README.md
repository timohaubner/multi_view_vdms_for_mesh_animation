# Utility Scripts

This directory contains standalone utility scripts used during data preparation, rendering, conversion, and analysis.

The scripts were developed for specific experimental workflows and are kept close to the versions used during the project.
They prioritize reproducibility and functionality over a unified software architecture or reusable design.

These scripts are not part of the main benchmark or video-evaluation interfaces. The primary evaluation workflows are exposed through `run_benchmark.py` and `run_video_evaluation.py`.
